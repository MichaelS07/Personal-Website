# NovaReach voice guide

Everything on this site is written as Michael Sowden: a hands-on digital marketing specialist in Christchurch who runs Google Ads, Meta, SEO, Klaviyo and CRO for ecommerce stores. Readers are NZ and AU store owners and marketing leads, not other agencies.

The goal is writing that sounds like one specific person with an opinion. `scripts/check_copy.py` enforces the hard rules below. Passing the checker is the minimum, not the target.

## Voice

- Write in first person ("I"). Never "we" or "our team". There is no team.
- NZ English: optimise, colour, analyse, programme, behaviour. Prices in NZD or AUD.
- Start with the substance. The first sentence should be about the reader's store or account, not about the topic in general.
- Take a position. If one option is better, say so and say why.
- Be specific: name the setting, the report, the menu path, the date, the number. Specifics make it sound human.
- Contractions always: it's, don't, you're, won't, isn't.
- Keep it grounded. No hype, no "exciting", no motivational sign-offs. End on the practical next step.
- Never invent results, clients or statistics. Only cite numbers from a source you can link, and say whose number it is (for example "Google's own figure").

## Hard rules (the checker fails on these)

- **No em dashes (—).** Use a full stop, a comma, a colon or brackets.
- **No semicolons** in body text.
- **Max three sentences per paragraph.** One-sentence paragraphs are fine.
- **No "this isn't X, it's Y" reframes**, including "it's not about X", "not just X but Y" and "not only X but Y". State the actual point directly.
- **No banned words.** Swap them for plain ones:
  leverage/utilise → use · robust → solid · seamless → smooth · comprehensive → full, thorough · crucial/pivotal → important, key · granular → detailed · landscape/realm/ecosystem → market, space, setup · actionable → practical, useful · findings → what I found · learnings → lessons · ultimately/furthermore/moreover/additionally → cut it, or "and", "also" · elevate → improve · foster → build · showcase → show · bespoke → custom · cadence → rhythm, schedule · bandwidth → time, capacity
- **No banned phrases:** "in today's…", "it's worth noting", "let's dive in", "deep dive", "at the end of the day", "the bottom line", "in conclusion", "moving forward", "unlock", "next level", "game changer", "pain points", "passionate about", and the rest of the list in `scripts/check_copy.py`.

## Patterns to avoid (the checker can't catch all of these)

- **Forced threes.** Don't group things in threes because it sounds tidy. Use two, or four, or one.
- **"From X to Y" sweeps** ("from first click to repeat order", "from startups to enterprises"). Name real examples instead.
- **Identical list items.** Real lists are uneven. Some items need a sentence of explanation, some are three words.
- **Metronome rhythm.** Mix short sentences with longer ones. If three sentences in a row are the same length, rewrite one.
- **Restating the headline** before answering. Get to it.
- **Balanced non-opinions** that hedge to the middle.
- **Stacked hedges** ("generally speaking, to some extent, it could be argued").

## Quick test

Read it out loud. Would Michael say this to a client on a call? If it sounds like it could have been written by anyone, add a specific detail or an opinion, or cut the sentence.
